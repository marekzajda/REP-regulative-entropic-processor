Two channels, two different jobs.

REPNet 4.0 deliberately avoids forcing the regulatory graph to imitate a semantic embedding. Semantic relevance and regulatory dynamics remain separate and auditable.

Semantic channel

Retrieval memory

MiniLM-based episodic retrieval provides a specific semantic memory channel. V4 learning is stored in a new isolated memory store rather than the historical V3 state.

Regulatory channel

Corrected graph dynamics

The V4 runtime uses the dissipative sign correction identified during forensic testing and measures relaxation rather than relying on the historical runaway confidence path.

Mechanistic readout

16D Regulatory Trace

Stability, relaxation, multiscale behavior, energy and flow evolution are compressed into an interpretable scale-invariant trace instead of a 384D semantic decoder.

REPNet 4.0 local runtime

The public site documents and launches the system. Computation remains local so the graph state, learning memory, GPU execution and development data stay under direct control.
